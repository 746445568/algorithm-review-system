# OJReview UI 重设计要求

目标：
- 以 OJReview_complete_midnight_blue_v2.html 为主要视觉参考。
- 只修改前端 UI，不修改后端接口。
- 保留现有业务逻辑。
- 默认支持深夜蓝主题，也支持浅色主题。
- 设置页不再显示外观切换，只保留右上角主题切换。
- AI 分析页单题分析不能使用原生 select，需要自定义选择器。
- 统计页柱状图必须从底部向上增长。
- 比赛日历页需要支持全部 / Codeforces / AtCoder 分类筛选。
- 仪表盘的近期比赛模块不要改动结构。

优先级：
1. 页面布局正确
2. 主题配色统一
3. 交互可用
4. 代码结构清晰
5. 视觉细节优化
